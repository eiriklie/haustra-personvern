# Haustra — personvern og brukerstøtte

Personvernerklæringen og supportsiden for [Haustra](https://apps.apple.com/app/id6814173375),
en iPhone-app for å føre logg over egen avføring med Bristol-skalaen. Sidene
publiseres med GitHub Pages:

- Personvernerklæring: https://eiriklie.github.io/haustra-personvern/
- Brukerstøtte: https://eiriklie.github.io/haustra-personvern/support/

Begge står på engelsk og norsk på samme side.

## Hvor de brukes

App Store Connect har to påkrevde felt for lenker, ett til
personvernerklæringen og ett til support. Det er disse to adressene. Supportsiden
finnes fordi Apple krever at support-lenken fører til faktisk hjelp, ikke bare
en e-postadresse.

## Hvorfor sidene ligger her

Kildekoden til appen ligger i et privat repo, og GitHub Pages krever betalt
plan for å publisere fra private repoer. Sidene har derfor sitt eget, offentlige
repo.

## Når sidene skal endres

Endrer en versjon av appen hva som skjer med data, oppdateres
personvernerklæringen **før** den versjonen slippes, og datoen øverst endres.
Det er lovet i selve erklæringen.

Begge språkene skal alltid si det samme. En endring på engelsk uten tilsvarende
endring på norsk, eller omvendt, er en feil.
